Station

The fixed position is used whenever there is no GPS fix. The beacon interval applies without a GPS fix or with SmartBeaconing off; 0 sends beacons only when you press Beacon.

Radio

On the radio: menu 66 COM PORT → OUTPUT = PACKET, SPEED as below; 67 DATA BAND → APRS on the 144.390 band. The data port can't transmit, so beacons and messages go to APRS-IS only (when logged in). Direwolf is stopped while this is selected.

Fallback hotspot

        
With no known network in range, the Pi runs its own access point: join it
          and open http://10.42.0.1:8080/. When a known network is back and
          nothing has been on the hotspot for 3 minutes, the Pi switches to the network.
          Name and password changes apply the next time the hotspot starts.
